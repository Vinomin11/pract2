# dependency-graph

Инструмент визуализации графа зависимостей пакетов Cargo (Rust).
Учебный проект по дисциплине «Конфигурационное управление», вариант 17.

Готовые менеджеры пакетов и сторонние библиотеки для получения
зависимостей не используются: только стандартная библиотека Python.

## 1. Общее описание

Приложение запускается из командной строки. Все настройки задаются
опциями командной строки. На текущем этапе (этап 1) приложение
проверяет параметры и выводит их в формате «ключ: значение».

Требуется Python 3.8 или новее. Устанавливать ничего не нужно.

## 2. Описание функций и настроек

### Настройки (опции командной строки)

| Опция | Описание |
|-------|----------|
| `--package`, `-p` | Имя анализируемого пакета |
| `--repo`, `-r` | URL репозитория (режим `remote`) или путь к файлу тестового репозитория (режим `test`) |
| `--mode`, `-m` | Режим работы: `remote` (по умолчанию) или `test` |

Правила проверки:

* имя пакета в режиме `remote`: буквы, цифры, `-` и `_`, первой должна
  быть буква;
* имя пакета в режиме `test`: одна большая латинская буква;
* в режиме `remote` репозиторий должен быть URL с `http://` или
  `https://`;
* в режиме `test` репозиторий должен быть существующим файлом.

При ошибке выводится сообщение в stderr, код завершения 2.

### Модули

| Файл | Назначение |
|------|------------|
| `src/main.py` | Точка входа, вывод параметров |
| `src/config.py` | Разбор и проверка параметров командной строки |
| `src/errors.py` | Исключения приложения |

## 3. Сборка и тесты

Сборка не требуется. Запуск тестов (из корня репозитория):

```
python -m unittest discover -s tests -t .
```

## 4. Примеры использования

Запуск (Linux/macOS: `./run.sh`, Windows: `run.bat`):

```
$ ./run.sh -p serde -r https://index.crates.io
package: serde
repo: https://index.crates.io
mode: remote
```

Примеры обработки ошибок:

```
$ ./run.sh -p serde
Ошибка: не задан репозиторий (--repo)

$ ./run.sh -p serde -r ftp://x
Ошибка: некорректный URL 'ftp://x': ожидается http:// или https://

$ ./run.sh -p serde -r https://index.crates.io -m fast
Ошибка: неизвестный режим 'fast', допустимо: remote, test

$ ./run.sh -p a -r graph.txt -m test
Ошибка: некорректное имя пакета 'a': ожидается одна большая латинская буква

$ ./run.sh -p A -r nofile.txt -m test
Ошибка: файл тестового репозитория не найден: nofile.txt
```
